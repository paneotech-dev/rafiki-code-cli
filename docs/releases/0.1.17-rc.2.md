# rafikicode 0.1.17-rc.2

Pre-release 0.1.17-rc.2 fixes the opt-in project map of [0.1.17-rc.1](./0.1.17-rc.1.md). The map stays off by default. Every item below is in [CHANGELOG.md](../../CHANGELOG.md).

This is a pre-release: `rafikicode update` and the install scripts at get.rafikiai.io stay on the latest stable release. To try it, install this version on purpose.

Linux and macOS:

```bash
curl -fsSL https://github.com/paneotech-dev/rafiki-code-cli/releases/download/v0.1.17-rc.2/install.sh | bash -s -- --version 0.1.17-rc.2
```

Windows, in PowerShell:

```powershell
& ([scriptblock]::Create((irm https://github.com/paneotech-dev/rafiki-code-cli/releases/download/v0.1.17-rc.2/install.ps1))) -Version 0.1.17-rc.2
```

## Fixes

- **A session no longer waits for a large project's map.** A map from an earlier session is used at once and refreshed in the background. Only a project with no map yet waits for the first build, for up to 90 seconds; `/map` builds it with no time limit.
- **A stopped build stops completely.** graphify starts a second process of its own; a build stopped at its time limit, or when Rafiki AI Code exits, now ends both.
- **`/map` counts the code files on a refresh.** It said "0 code files" when the map was already there.
- **`/map` and `/map off` update `/mcps` and the status bar.** They showed the server as connected after `/map off`.

See [Project map](../project-map.md).
