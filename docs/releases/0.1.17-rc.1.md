# rafikicode 0.1.17-rc.1

Pre-release 0.1.17-rc.1 adds an opt-in project map: a code graph of your project that the agent queries through tools when it needs it. It is off by default; with it off, this build behaves as 0.1.16. Every item below is in [CHANGELOG.md](../../CHANGELOG.md).

This is a pre-release: `rafikicode update` and the install scripts at get.rafikiai.io stay on the latest stable release. To try it, install this version on purpose.

Linux and macOS:

```bash
curl -fsSL https://github.com/paneotech-dev/rafiki-code-cli/releases/download/v0.1.17-rc.1/install.sh | bash -s -- --version 0.1.17-rc.1
```

Windows, in PowerShell:

```powershell
& ([scriptblock]::Create((irm https://github.com/paneotech-dev/rafiki-code-cli/releases/download/v0.1.17-rc.1/install.ps1))) -Version 0.1.17-rc.1
```

## Project map

- Install graphify yourself (Python 3.10 or later): `uv tool install "graphifyy[mcp]"`, `pipx install "graphifyy[mcp]"`, or on Windows `py -m pip install --user "graphifyy[mcp]"`.
- Turn the map on with `RAFIKICODE_MAP=1` for a run, or `"map": {"graphify": true}` in `rafikicode.json`.
- Each session then builds or refreshes the map and gives the agent four tools: `graphify_query_graph`, `graphify_get_neighbors`, `graphify_get_node` and `graphify_shortest_path`. Nothing is added to the prompt; a tool costs tokens only when the agent calls it.
- `/map` builds or refreshes the map now and shows the number of code files, names and links and the time it took. `/map off` removes the tools for the rest of the session. With graphify missing, `/map` shows the one install command for your system and installs nothing.
- graphify runs in code only mode with every model backend off (`GRAPHIFY_BACKEND=none`) and the provider keys blanked for its processes, so no file content leaves your machine. The map is saved in the cache folder of Rafiki AI Code, never in your project.

See [Project map](../project-map.md).
