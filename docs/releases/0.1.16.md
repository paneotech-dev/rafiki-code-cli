# rafikicode 0.1.16

Release 0.1.16 reports an unreachable gateway in seconds and uses the product's current names and addresses. Every item below is in [CHANGELOG.md](../../CHANGELOG.md).

Update:

```bash
rafikicode update
```

New install:

```bash
curl -fsSL https://get.rafikiai.io | bash
```

On Windows, in PowerShell (then use Windows Terminal):

```powershell
irm https://github.com/paneotech-dev/rafiki-code-cli/releases/latest/download/install.ps1 | iex
```

## Fixes

- **A gateway that drops packets is reported in seconds.** Behind a firewall, captive portal or dead route, `rafikicode run` waited about 4.5 minutes with no output. It now stops after 10 seconds with `Cannot reach the model gateway` and exit code 4. `RAFIKICODE_CONNECT_WAIT` sets the wait; `0` turns it off.
- **`rafikicode usage` no longer calls a working key revoked.** A key the gateway accepts but Rafiki AI Console does not know now gets the same message as `whoami` (exit 1). A revoked key still asks you to sign in (exit 2).

## Names and addresses

- The product is named Rafiki AI Code, the tiers Rafiki AI Fast, Rafiki AI Pro and Rafiki AI Max, and the console Rafiki AI Console. Model ids (`rafiki/rafiki-fast` and the others) are unchanged.
- Editors (Zed, JetBrains) list the tiers as `Rafiki AI Fast` instead of `Rafiki/Rafiki Fast`.
- Signed out, the message is `Not signed in. Run: rafikicode login`, with the sign-up address https://accounts.rafikiai.io/signup?product=code. The installers print the same sign-up line.
- Keys for servers and CI are created on API keys in Rafiki AI Code at https://code.rafikiai.io/keys, and every message about keys points there. A key `logout` cannot revoke is signed out at https://code.rafikiai.io/sessions.
- Shorter messages for keys Rafiki AI Console does not know or that were not made for Rafiki AI Code.

## Tests
