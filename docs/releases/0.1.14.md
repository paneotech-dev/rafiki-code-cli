# rafikicode 0.1.14

Release 0.1.14 brings the cost of a task back down after 0.1.13 and fixes a task that could stop halfway without a word. Every item below is in [CHANGELOG.md](../../CHANGELOG.md) with its detail.

Update:

```bash
rafikicode update
```

Then quit any open window and start it again; `rafikicode --continue` reopens your last conversation.

New install:

```bash
curl -fsSL https://get.rafikiai.io | bash
```

On Windows, in PowerShell (then use Windows Terminal):

```powershell
irm https://github.com/paneotech-dev/rafiki-code-cli/releases/latest/download/install.ps1 | iex
```

## Lower cost per task

- **At most 3 screenshots per task.** After the third capture the agent finishes from the last report instead of rendering the page again for polish. The design guide stops asking for captures once one shows no problem.
- **Checks run again only when needed:** a check is repeated only after the code it covers has changed.
- **Acceptance criteria are ticked off in one update** instead of one request per criterion.

## Fixes

- **No more silent stops.** A step that comes back with no text and no tool call used to end the task, even in the middle of its work. It is now tried again once, with one line saying so; if the retry is empty too, the task stops with a plain error and `rafikicode run` exits 1.

## Tests

The full `packages/opencode` suite and the interface suite run on the release commit, the release build was measured on the release task set on Rafiki Fast and Rafiki Pro, and the release gate installs, starts, signs in and runs a task on all thirteen builds before anything is published.
