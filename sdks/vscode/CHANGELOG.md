# Changelog

## 0.1.0

First Rafiki Code release for VS Code.

- Open Rafiki Code in an editor tab or the terminal panel, one session per tab.
- Send the current file, selection or explorer file to the session prompt.
- Sign in and sign out with your Rafiki Console account, shared with the `rafikicode` command. With rafikicode 0.1.3 or later the Console lists the key as an editor sign in (surface `ide`).
- Status bar item with the key state and the tier; Doctor and Show Account commands.
- Tier picker (fast, pro, max) for the next session.
- Finds `rafikicode` from the `rafikicode.path` setting, `PATH`, or `~/.rafikicode/bin`.
